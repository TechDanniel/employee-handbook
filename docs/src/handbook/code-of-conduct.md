# 02. 行为准则

## 基本原则

- 尊重：尊重每位同事的背景、表达与边界。
- 专业：对事不对人，事实与数据优先。
- 合规：遵守法律法规与公司制度。

## 职场行为（示例）

- 禁止歧视、骚扰、霸凌与报复。
- 不传播或展示令人不适的内容（含低俗、暴力、仇恨）。
- 会议与协作保持专注：提前准备、按时开始、明确结论与负责人。

## 利益冲突

- 如与供应商/客户/竞品存在亲属或投资关系，应主动申报。
- 不得利用职务便利谋取不当利益。

## 礼品与招待（简化示例）

- 原则：不影响判断、可公开、可解释。
- 不确定时：先问直属负责人或合规/财务。

## 对外表达

- 对外发布（媒体、社交平台、公开演讲）涉及公司信息时需遵循公司流程。
- 禁止泄露客户信息、未公开财务/产品计划、内部代码与文档。
