# 04. 休假与考勤

> 本章为演示示例。各类假期天数、适用条件与审批流程以公司制度与当地法规为准。

## 常见假期（示例分类）

- 年假：按工龄与制度享有；建议提前规划，避免集中在项目关键期。
- 病假：如需连续请假，按要求提供证明材料。
- 事假：建议说明事由与预计时间，便于团队安排。
- 婚/产/陪产/育儿假：按当地法规与公司制度执行。

## 请假流程（简化）

1. 提前在考勤系统/IM 流程发起申请
2. 直属负责人审批
3. 同步项目协作人（必要时）

## 考勤与迟到早退（示例口径）

- 如遇突发情况（交通/健康/家庭），尽快在团队群说明并补流程。
- 长期作息调整应与直属负责人提前对齐。

## 加班与调休（示例）

- 是否加班：以工作需要与团队管理为准。
- 如可调休：建议在加班后尽快安排，避免疲劳累积。
