# 05. 信息安全

## 账号与密码

- 开启多因素认证（MFA）（如系统支持）。
- 不共享账号；离岗/转岗按流程回收权限。
- 密码建议使用密码管理器，避免重复使用。

## 设备与数据

- 公司设备优先用于工作；安装软件遵循 IT 规范。
- 重要数据分级：
  - 公开：可对外公开
  - 内部：仅公司内部
  - 机密：客户数据、未发布信息、密钥等
- 机密信息不得通过个人邮箱/网盘/非授权 IM 传输。

## 办公场景安全

- 公共场所注意防窥；离开座位锁屏。
- 会议室白板、纸质材料及时清理。

## 事件上报（示例）

如发现以下情况请尽快上报：

- 账号疑似被盗、异常登录
- 误发敏感文件/链接
- 设备遗失或被盗

上报信息建议包含：时间、涉及系统、影响范围、已采取措施。
