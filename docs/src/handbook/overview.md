# 01. 总览与入职

## 我们是谁（示例）

- 使命：用简单可靠的产品解决真实问题。
- 价值观：客户第一、坦诚沟通、对结果负责、持续学习。

## 雇佣与试用（示例口径）

- 录用信息以 offer/劳动合同为准。
- 试用期目标：明确岗位职责、完成入职任务、通过 1 次试用期评估。

## 入职清单（第一周）

- [ ] 完成账号开通：邮箱、IM、代码仓库/工单系统（如适用）
- [ ] 领取设备：电脑/门禁/工牌（如适用）
- [ ] 阅读手册：工作方式、休假考勤、信息安全
- [ ] 与直属负责人对齐：
  - 30 天目标
  - 主要协作人
  - 绩效与反馈节奏

## 沟通渠道

- 日常沟通：IM 群/项目群（尽量在群里同步可复用信息）
- 正式流程：工单/邮件（需要可追踪、可归档的事项）
- 紧急事件：电话/紧急群（仅限影响业务或安全的情况）

## 反馈与申诉（示例）

- 优先与直属负责人沟通。
- 如不便直接沟通，可联系 HRBP 或指定合规/申诉渠道（以公司实际为准）。
